Key Modules & Curriculum

1. Foundational Linux Administration

  • Linux Architecture & FHS: Navigating filesystem, configs, logs
  • User & Group Management: Sudoers, password policies
  • Permissions & ACLs: chmod, chown, Access Control Lists
  • Process & Service Management: systemd, systemctl, monitoring
  • Package Management: apt, yum/dnf – install, update, maintain

2. Linux Hardening & Defensive Security

  • Network & Firewall: ufw rules, interface management
  • Secure Remote Access (SSH): Disable root, key‑based auth
  • System Auditing & Logging: auditd, log centralization
  • Kernel Hardening: sysctl.conf for network‑layer defense

3. Vulnerability Assessment & Threat Detection

  • Vulnerability Scanning: Lynis for config & patch audits
  • File Integrity Monitoring (FIM): Track changes to critical files
  • Log Analysis & Threat Hunting: Identify brute‑force & anomalies
  • Malware & Rootkit Detection: Scan for hidden threats & backdoors

4. Enterprise Scale: Automation & Identity

  • Centralized Authentication: Manage user identity at scale
  • Container Security: Namespaces, cgroups (Docker/Podman)
  • Automated Hardening: Enforce baselines with Ansible

Hands-On Learning Experience

  • Interactive Terminal Labs: Practical exercises that reinforce theory with execution.
  • Real-World Scenarios: Troubleshoot permissions, lock down SSH, write firewall rules, investigate compromises.
  • Takeaway Resources: Implementation checklists, configuration scripts, and lab guides.
